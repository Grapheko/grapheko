# Carrousels Instagram

Modèle de référence : `carousel-2026-11-per.html` (7 vues 1080 × 1350, polices du site, couleurs Grapheko).
Rendu : `node scripts/instagram/shoot.js carousel-2026-11-per.html` → JPEG qualité 92 dans ce dossier.

Structure d'un carrousel : 1. couverture (la croyance + la réponse courte, fond jaune) · 2. le contexte expliqué simplement ·
3. la courbe redessinée pour mobile · 4-5. un cas par vue (« la règle promet » barré / « le vrai calcul donne » en grand) ·
6. ce que la courbe ne dit pas (fond encre) · 7. appel à l'action, lien en bio, mention « contenu éducatif ».
Mêmes règles éditoriales que la newsletter : débutant complet, pas de recommandation, chiffres issus d'un calcul.
